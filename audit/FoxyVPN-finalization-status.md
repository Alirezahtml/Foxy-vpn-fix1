# FoxyVPN — وضعیت نهایی‌سازی و شواهد

تاریخ: 2026-10-31  
نسخه‌ی پروژه: **1.0.13 (versionCode 50)**

این سند تغییرات این مرحله و محدودیت‌هایی را که از build یا منبع کد قابل اثبات‌اند جدا می‌کند. Build موفق به‌تنهایی اثبات عملکرد روی شبکه، حساب Firefox یا دستگاه واقعی نیست.

## خواسته‌ها، یکی‌یکی

1. **هاله‌ی نوری و رنگ دلخواه — انجام‌شده در UI**
   متن‌های Gemini/Google AI Studio از UI پاک شده‌اند. انتخاب رنگ RGB/HEX برای accent برنامه و رنگ هاله در picker مشترک وجود دارد و در Settings و Home قابل دسترسی است؛ یک تم پایه حفظ شده تا فهرست presetها شلوغ نشود. نوشته‌های ممنوع در `app/src/main/java` و `app/src/main/res` با جست‌وجوی متنی پیدا نشدند. تغییرات animation/performance هاله در کد قبلی پروژه حفظ شده‌اند.

2. **پالت رنگ — مطابق منظور کاربر، کم‌ازدحام و سفارشی**
   تغییر موقتی که همه‌ی presetها را هم‌زمان نشان می‌داد برگردانده شد؛ فقط تم پایه نمایش داده می‌شود و کاربر از picker رنگ دلخواه می‌سازد. کنترل رنگ روی صفحه‌ی Settings با دکمه‌ی قابل‌مشاهده دارد و در Home نیز از کنترل theme قابل دسترسی است.

3. **نشانگرهای متحرک و آیکن رسمی برنامه — شواهد حضور در کد**
   آیکن برنامه (`foxy_official_icon`) در launcher foreground، Home، Splash/Login، اعلان سرویس VPN و ویجت استفاده می‌شود. Dynamic Island و markerهای map از جریان‌های انیمیشن Compose استفاده می‌کنند.

4. **اندازه و معناشناسی سرعت در Dynamic Island — اصلاح‌شده**
   آیکن سرعت compact به 16dp افزایش یافته و در همان ردیف با مقدار RX قرار می‌گیرد؛ سرعت‌سنج از همان نرخ RX استفاده می‌کند، نه مجموع RX+TX. وقتی پرچم واقعی موجود نیست، آیکن سرعت به‌جای پرچم نمایش داده نمی‌شود؛ فقط نشانگر وضعیت خنثی می‌آید.

5. **آیکن‌های Telegram/Instagram — جایگزین‌شده**
   نقاشی Canvas با PNGهای لوگوهای brand pack جایگزین شده است: `foxy_telegram_official.png` و `foxy_instagram_official.png`.

6. **نقشه‌ی خروجی VPN — ادعاها و مختصات اصلاح‌شده**
   شهر `mnc` (Manchester) در whitelist مختصات موجود است؛ مختصات شهر ناشناخته از کشور به‌عنوان پین شهری جعلی استفاده نمی‌شود. نقشه کشور خروجی را فقط پس از دریافت egress IP معتبر نشان می‌دهد. متن قبلی «مسیر مستقیم زنده/رمزشده» حذف شده و به «کشور خروجی تأییدشده؛ مسیر شماتیک و فاصله‌ی تقریبی» تغییر کرده است؛ فاصله‌ی نمایش‌داده‌شده مسیر واقعی بسته‌ها یا hop-by-hop نیست. تست واحد مختصات برای شهرهای known/unknown و fallback کشور اضافه شده است.

7. **متن، چیدمان و RTL — اصلاحات هدفمند؛ نه ادعای بازنویسی تمام رشته‌ها**
   برچسب‌های تغییرکرده در فارسی، عربی و انگلیسی ترجمه‌ی جداگانه دارند. `Theme.kt` جهت RTL/LTR را در سطح برنامه برای Persian/Arabic اعمال می‌کند. در این مرحله ممیزی تصویری تمام صفحه‌ها و بازنویسی سراسری همه‌ی رشته‌های برنامه انجام نشده است.

8. **آپشن‌های نمایشی — موارد مشخص‌شده متصل شده‌اند**
   - Gaming Mode مقدار MTU=1360 را فقط در Auto mode انتخاب می‌کند، اعمال MTU باعث reconfigure تونل می‌شود، و Server Scanner در زمان روشن بودن Gaming Mode متوقف/غیرفعال می‌شود. بررسی سلامت تونل و auto-recovery عمداً خاموش نمی‌شوند.
   - Battery Saver قفل Wi‑Fi پُرکارایی را آزاد می‌کند، فاصله‌ی نمونه‌برداری آمار سرعت را از 2s به 5s می‌رساند و health checks را فعال نگه می‌دارد. تغییر سوییچ در تونل فعال از طریق runtime-settings اعمال می‌شود.
   - Smart Ping پس از اسکن دستی، پایدارترین نتیجه را به‌عنوان سرور منتخب ذخیره می‌کند؛ اتصال جاری را مخفیانه قطع یا تعویض نمی‌کند و کاربر باید دکمه‌ی اتصال را بزند.
   - Auto-Reconnect و Keep-Alive از تغییرات قبلی پروژه باقی هستند. این سند ادعا نمی‌کند که هر کنترل در تمام بخش‌های برنامه بررسی دستی شده است.

9. **پروتکل‌ها — برچسب‌گذاری صادقانه**
   کد محلی Firefox Go core مسیرهای HTTP/2 و HTTP/3/QUIC و fallback دارد؛ badge اتصال اکنون ابتدا «Negotiating…» و پس از اتصال از transport واقعی core مقدار می‌گیرد. HTTP/1.1 در core این پروژه پیاده‌سازی نشده و باید unavailable بماند. HTTP/3/QUIC نیز به‌تنهایی پشتیبانی UDP خام همه‌ی بازی‌ها را ثابت نمی‌کند؛ UI محدودیت relayهای TCP-based را توضیح می‌دهد. جست‌وجو و مستند منابع در [بررسی پروتکل‌ها](protocol-research.md) ثبت شده است.

10. **کارایی، پایداری و رفع باگ — build-verified؛ runtime نیازمند دستگاه/شبکه**
    speed stats اکنون از counterهای core خوانده می‌شود؛ auto-recovery bounded و health checks حفظ شده‌اند. کاهش telemetry در Battery Saver به recovery آسیب نمی‌زند. این محیط به شبکه‌ی واقعی کاربر و حساب Firefox متصل/اجرا نکرده، پس سرعت end-to-end، نرخ قطع‌شدن، HTTP 406/anti-bot و رفتار روی دستگاه واقعی در این گزارش اثبات نشده‌اند.

## مانع Release امضاشده

فایل `/home/ubuntu/work/foxyvpn-merged/FoxyVPN/release-keystore.jks` موجود است، اما محیط اجرای Gradle این نام‌ها را نداشت: `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`, `SIGNING_STORE_PASSWORD`. بنابراین package Release امضاشده عمداً اجرا/اعلام نشده است. برای آنکه این اجرای Gradle بتواند Release بسازد، مقادیر باید در محیطی که Gradle اجرا می‌شود به همین نام‌ها صادر شوند؛ مقادیر محرمانه را در گفت‌وگو نفرستید.
