# Performance Baseline

No trustworthy performance numbers were collected. Android SDK, NDK, device, and live VPN server access were unavailable. Any latency, throughput, CPU, memory, packet-loss, or startup claims would be fabricated.

Required follow-up measurements on a configured device: cold start, TUN establishment, control-plane connection, verified data-plane request, sustained throughput, CPU/RAM by core, disconnect cleanup, and repeated network transitions. Measurements need timestamps, sample counts, freshness windows, and the same server/configuration for comparison.
